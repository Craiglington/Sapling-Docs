Documentation

Component Driven Development

  • Component: Create components and add them to the custom element registry.

Reactivity

  • Observable: Notify subscribers with values or events.
  • Subject: An Observable with state.
  • State: A state container made with Subjects.
  • Value: One-way data binding from variables to element properties, attributes, and classes.

Single-Page Application

  • Router: Define URL routes and inject Components directly into the DOM.
