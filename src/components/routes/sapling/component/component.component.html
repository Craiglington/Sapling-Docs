Component

Overview

A Component is an extension of an HTMLElement. It can be extended to create custom HTML elements.

When creating a Component, a template must be provided. Style sheets can also be provided. Because web components create a shadow DOM, style sheets will not affect elements outside of that component.

Additionally, every custom Component must be added to the custom element registry. This makes a component available for use within a template.

In the following example, <app-custom-component></app-custom-component> is now a valid html element.

class CustomComponent extends Component { constructor() { super({ templateUrl: "/src/components/custom/custom.component.html", styleUrls: ["/src/components/custom/custom.component.css"] }); } } window.customElements.define("app-custom-component", CustomComponent);

Finally, all custom Components can implement certain lifecycle callbacks. For this and more information regarding custom HTML elements, view the guide available at MDN.
